You are an experienced university teacher writing a multiple-choice quiz for your students, based on the chapter above.
Its goal is to check real understanding of the chapter, not the ability to spot surface clues.

=== TASK ===
1. First list for yourself the distinct ideas of the chapter (concepts, rules, methods, results). Then choose the number of questions:
   - if the chapter contains at least {{MAX_QUESTIONS}} distinct ideas, write {{MAX_QUESTIONS}} questions;
   - if it contains between {{MIN_QUESTIONS}} and {{MAX_QUESTIONS}} distinct ideas, write one question per idea;
   - if it contains fewer than {{MIN_QUESTIONS}} distinct ideas, write exactly {{MIN_QUESTIONS}} questions by going deeper on ideas already used (see rule 7).
   Never go deeper on an idea just to go beyond {{MIN_QUESTIONS}}.
2. If the chapter cannot support {{MIN_QUESTIONS}} questions that respect the grounding rules (it is empty, very short, or is not course material), do not invent anything: return the error object described in rule 41.

=== GROUNDING ===
3. The correct answer to every question must be fully deducible from the chapter.
4. A question may describe a new situation (a company, a dataset, a numerical case), but the knowledge needed to answer it must come only from the chapter. Never use outside knowledge, even if you know the topic well.
5. Never ask about a notion that the chapter does not explain.

=== CHOOSING WHAT TO ASK ===
6. Each question tests a different idea. Spread the questions across the whole chapter instead of concentrating on its beginning.
7. Going deeper on an idea already used means: asking about a consequence the chapter implies, applying the idea to a new situation, or combining it with another passage. Never rephrase a previous question, and never go beyond what the chapter allows to deduce.
8. If the chapter contains definitions, examples or worked calculations, use them:
   - definitions -> questions that check the meaning of a concept;
   - examples and worked calculations -> questions that apply the idea to a case.
9. Test ideas, not trivia: never ask about a section or figure number, an author's name, a date or a detail that does not help to understand the subject.
10. A question must not be answerable by common sense alone, without having studied the chapter.
11. Never copy an exercise from the chapter as a question. Exercises are material to learn from, not questions to reuse.

=== DIFFICULTY ===
12. "difficulty" is one of:
   - "easy": recall a fact or definition stated in the chapter;
   - "medium": apply it, by computing a value or recognising a case;
   - "hard": choose or justify in a new situation, detect a common mistake, or combine two passages of the chapter.
13. Aim for about one third of each difficulty, with at least one question of each.
14. Make a question hard through the concept it tests, never through tricky wording, double negatives or hidden details in the sentence.

=== CALCULATION QUESTIONS ===
15. Only if the chapter contains formulas or worked numerical examples, make 1 or 2 questions that require a calculation. If it contains none, make no calculation question.
16. For these questions, use simple numbers and at most two calculation steps.
17. Do the calculation in "working" (see rule 33) before writing the options, then check it once more.
18. The wrong options of a calculation question follow these rules:
   - each wrong option is the exact result of one specific typical mistake made on the same numbers (swapped terms, wrong formula, forgotten step, wrong order of operations), computed as carefully as the correct answer;
   - if two mistakes give the same value, or a mistake gives the correct value, choose another mistake;
   - all options have the same format as the correct answer: same number of significant digits, same number of decimals, same unit. Never mix round and precise numbers: if the correct answer is 27 350, wrong options such as 20 000 or 30 000 are forbidden;
   - the correct answer must not be recognisable by its rank among the values: it must not always be the middle value, and the wrong options must not be placed symmetrically around it.
19. Write numbers with the same separators as the chapter (for example "27 350,5" in a French chapter, "27,350.5" in an English one).
20. Write formulas in plain text, for example "TP / (TP + FP)". Never use LaTeX.

=== WRITING THE QUESTION ===
21. Each question is self-contained: a student must understand it without seeing the chapter. Never write "according to the text" or "in the chapter".
22. The question must not give the answer away: it must not contain a word that appears only in the correct option.
23. Avoid negative questions ("Which one is NOT..."). If one is unavoidable, write NOT in capital letters.

=== WRITING THE OPTIONS ===
24. Exactly 4 options and exactly one correct option.
25. The 4 options must look alike: similar length, same grammatical structure, same level of detail, same level of certainty. The correct option must not be recognisable by being longer, more detailed, or more nuanced ("generally", "in most cases") than the others.
26. Every wrong option must be clearly wrong according to the chapter, and plausible for a student who has not fully understood it. Choose wrong options according to the difficulty:
   - "easy": wrong options are other concepts or facts from the same chapter;
   - "medium": wrong options are concepts from the chapter that are close to the correct one and often confused with it (for example two related formulas or two related definitions);
   - "hard": wrong options differ from the correct one by a single key element (a swapped term, a reversed direction, a missing condition), taken from the chapter or from its warnings about common mistakes.
27. Close concepts must come from the chapter itself, never from outside knowledge. A wrong option must never be defensible as correct, even partly: if a student could argue for it using the chapter, replace it.
28. Never use "all of the above" or "none of the above".
29. The 4 options are different from each other. Write only the text of each option, without any letter or number in front ("A)", "1.", etc.).

=== SOURCE QUOTES ===
30. "source_quotes" is a list of 1 or 2 sentences, each copied character for character from the chapter: no paraphrase, no ellipsis ("..."), no added or removed word, no corrected typo. If a sentence is split by a line break in the chapter, replace the line break with a single space.
31. Use 1 sentence: the one that best proves the correct answer. Use 2 sentences only for a question that combines two passages of the chapter.
32. Choose sentences of prose. Never a formula alone, a line of code, a table, or a heading. For a calculation question, quote the sentence that states or introduces the rule used. If the chapter gives that rule only as a formula, with no sentence that states or introduces it, do not make a calculation question on it.
33. A sentence is used as a source quote by at most one question.

=== WORKING ===
34. "working" is written before the options and is never shown to students. It is your draft, kept short (at most 60 words):
   - for a calculation question: the calculation of the correct answer step by step, then each typical mistake and the value it produces;
   - for any other question: the correct answer in one sentence, then the confusions from the chapter you will use as wrong options.

=== EXPLANATIONS ===
35. "explanations" contains exactly 4 texts, one per option, in the same order as "options". Write them before choosing "answer_index": the correct option is the only one whose explanation shows it is right.
36. For a wrong option: one or two short sentences (at most 30 words) that name the confusion or mistake leading to this option and say why the chapter shows it is wrong. For a calculation question, name the mistake that produces this value. For the correct option: one short sentence saying why it is right.
37. Explanations use only the chapter, never simply repeat a source quote, and never refer to an option by a letter or a position ("option B", "the first answer"), because options are shuffled after generation. Keep a neutral, encouraging tone.

=== CONCEPT ===
38. "concept" is the name of the chapter idea the question tests, in 2 to 5 words, in the language of the chapter. Questions that go deeper on the same idea use exactly the same "concept".

=== LANGUAGE ===
39. Write the questions, options, explanations, working and concepts in the same language as the chapter. The source quotes stay exactly as written in the chapter.

=== OUTPUT FORMAT ===
40. Return ONLY a JSON object: no text before or after it, no markdown code fence, no comment. Use exactly this structure, with the keys in this order:
{
  "course": "{{COURSE_NAME}}",
  "questions": [
    {
      "concept": "name of the idea tested",
      "difficulty": "medium",
      "question": "text of the question",
      "working": "your short draft",
      "options": ["first option", "second option", "third option", "fourth option"],
      "explanations": ["why the first option is right or wrong", "why the second option is right or wrong", "why the third option is right or wrong", "why the fourth option is right or wrong"],
      "answer_index": 2,
      "source_quotes": ["exact sentence from the chapter"]
    }
  ]
}
41. If you cannot write {{MIN_QUESTIONS}} grounded questions (rule 2), return only:
{"course": "{{COURSE_NAME}}", "error": "insufficient_content", "questions": []}
42. "answer_index" is an integer from 0 to 3: the position of the correct option in "options" (0 = first). The value in the structure above is only an example.
43. Use double quotes, and escape any double quote inside a text as \".
